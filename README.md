# HexCraft — v0.1 (игровое меню + редактор ресурсов)

Мобильная/ПК игра-стратегия с шестиугольной картой, без ИИ, с большой кастомизацией.
В этой версии: игровое меню и **рабочий редактор ресурсов**.

## Как запустить

Просто открой `game/index.html` в браузере (двойной клик). Для телефона — можно
раздать по локальной сети:

```bash
cd game && python3 -m http.server 8000
# затем открыть http://<IP-компьютера>:8000 на телефоне
```

Позже для APK/EXE этот же код оборачивается в Capacitor/Cordova (APK) или Tauri/Electron (EXE) —
хранилище уже сделано так, чтобы данные пользователя переживали сборку (см. ниже).

## Структура

```
game/
├── index.html          # экраны меню (Главное / Редактор модов / Редактор ресурсов / Об игре)
├── style.css           # мобильный тёмный UI
├── storage.js          # локальное хранилище (localStorage): свои картинки в base64 + свои ресурсы
├── data.js             # встроенные картинки и стандартные ресурсы (readonly)
├── game.js             # навигация + логика редактора ресурсов
└── assets/images/      # ← СЮДА КИНЬ 2 КАРТИНКИ ЗОЛОТА (см. ниже)
```

## Куда положить 2 картинки золота

Положи файлы сюда (имена должны быть именно такие, они уже зарегистрированы в `data.js`):

- `game/assets/images/gold_coin.png` — «Золотая монета»
- `game/assets/images/gold_bar.png`  — «Золотой слиток»

Сейчас там лежат временные заглушки (нарисованные процедурно), просто замени их своими
PNG/JPG размером ~64–256px. Если захочешь другое имя файла — добавь/поменяй запись
в массиве `HCData.builtinImages` в `game/data.js`:

```js
{ id: "img_gold_coin", name: "Золотая монета", src: "assets/images/gold_coin.png" },
```

Также во встроенных есть плиточные заготовки из emoji (Древесина 🪵, Камень 🪨, Еда 🌾, Кристалл 💎) —
их можно позже заменить на настоящие картинки тем же способом.

## Что умеет редактор ресурсов (v0.1)

Главное меню → **Редактор модов** → **Редактор ресурсов**:

1. **Вкладка «Ресурсы»**
   - список всех ресурсов: стандартные (🔒 Gold/Wood/Stone/Food/Crystal) + свои;
   - **стандартные ресурсы нельзя изменить или удалить** — открываются только на просмотр;
   - кнопка **«＋ Создать свой ресурс»**: название + картинка → Сохранить;
   - клик по своему ресурсу: изменить название, заменить картинку, сохранить, удалить.

2. **Вкладка «Картинки»**
   - выбор среди встроенных картинок игры;
   - **«📁 Добавить свою картинку…»** — обычный `<input type=file>` (на телефоне открывается
     системный выбор файлов/галереи);
   - загруженные картинки можно **переименовывать (✎)** и **удалять (✕)**;
   - удаление заблокировано, если картинку использует созданный ресурс.

3. **Замена картинки у ресурса** — модалка «Выбор картинки»: встроенные + мои загруженные +
   загрузка новой прямо оттуда.

## Как хранятся картинки пользователя (важно для APK/EXE)

- Файл читается через `FileReader` → прогоняется через `canvas` (масштаб ≤128px) →
  сохраняется как **base64 dataURL** в `localStorage` (`storage.js`, ключ `hexcraft.images`).
- `localStorage` внутри WebView привязан к приложению, поэтому картинки работают после
  перезапуска и после экспорта в **APK** (Capacitor/Cordova) и **EXE** (Tauri/Electron/NW.js).
- Ограничение на исходник — 1.5 МБ (защита от переполнения localStorage; при нехватке места
  показывается предупреждение). Позже можно расширить до Filesystem API, интерфейс это позволяет.

# --- Push & Pull Request ---

Для отправки кода на GitHub и создания PR используй скрипт `push-pullrequest.ps1`
(Windows PowerShell): он коммитит изменения, пушит ветку
`feature/v0.1-game-menu-resource-editor` в `https://github.com/BlackAimo/hexcraft.git`
и создаёт Pull Request (через `gh` или открывает страницу `compare/main...ветка` в браузере).
Подробности — в комментариях внутри скрипта.

### Способ 2: без учётных данных в песочнице — git bundle

В этом рабочем окружении нет доступа к GitHub (репозиторий приватный, токена нет),
поэтому весь код v0.1 упакован в `hexcraft-v0.1.bundle` (полная git-история, 2 коммита).
Скачай bundle и у себя в папке репозитория выполни:

```powershell
git pull ..\hexcraft-v0.1.bundle feature/v0.1-game-menu-resource-editor:feature/v0.1-game-menu-resource-editor
git push origin feature/v0.1-game-menu-resource-editor
```

Затем создай PR: `https://github.com/BlackAimo/hexcraft/compare/main...feature/v0.1-game-menu-resource-editor`
(или через скрипт `push-pullrequest.ps1`, если работаешь локально с клонированным репо).

### Способ 3: токен прямо здесь (я сам создам PR)

Если дашь Personal Access Token, я выполню push и открою PR сам:
1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token
2. Выбери репозиторий `BlackAimo/hexcraft`, scope: **repo**
3. Пришли токен сюда — я сделаю `git push` и создам Pull Request через GitHub API.
